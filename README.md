# WiFiScope Android 0.2

Versión autónoma para hacer el mapa de calor directamente en Android.

Funciones: cargar plano, escanear Wi-Fi, seleccionar BSSID, marcar puntos con RSSI, generar heatmap IDW, borrar último punto y exportar PNG.

Flujo recomendado: cargar plano -> escanear -> seleccionar BSSID -> tocar posición -> desplazarse -> volver a escanear -> tocar nueva posición -> generar mapa.

Sube el contenido de esta carpeta a la raíz del repositorio y ejecuta el workflow `Build WiFiScope Android APK`.
